# SolidWorks Windows 工作台

将用户的机械任务转成可编辑零件，并提供可复核的尺寸、孔位、体积、约束状态及文件验证结果。

## 选择当前阶段

- 已有 SolidWorks MCP：先发现**当前聊天实际加载的工具**，再查询连接与文档列表。配置里有工具，不代表当前聊天已加载；缺少新工具时再要求重载客户端。
- 还未部署，或准备换工作目录：读取 [部署步骤](references/setup.md)，使用随附脚本。默认先诊断和生成配置预览；尊重用户已经给出的安装与修改授权。
- 开始建模或修改参数：读取 [建模与验收](references/modeling.md)。优先使用已验证的原生尺寸方案。
- 连接、尺寸、方程失败：仅按需要读取 [故障定位](references/troubleshooting.md)。不要把一次机器故障推广为所有机器的结论。

## 本服务的实际边界

- 用户先手动打开 SolidWorks。本服务连接已有进程，禁止自动启动、任意 Python 执行和宏。
- 查询模式只暴露 3 个工具；建模模式暴露 19 个。查询能力探测只解析成员名称，不执行被探测方法。
- 修改操作仅作用于本服务进程新建的零件。服务重启后已有文件只读打开；不能将只读打开当成获得写权限。
- 保存必须指定工作区 CAD 内不存在的 .SLDPRT 路径。新版本使用新文件名；关闭操作拒绝丢弃未保存修改。
- 这些检查用于减少误操作，不构成 Windows 用户权限的安全隔离。
- SolidWorks 2018–2026 的兼容性是上游项目的声明。本技能的实际 CAD 验证范围为一台 Windows 机器上的 SolidWorks 2023 SP0.1、Python 3.14.7；其他组合需现场验证。

## 执行与判断

1. 确认目标尺寸、单位、输出文件和当前文档；不要把用户打开的已有工程文件当成新建测试件。
2. 检查每次工具返回的 ok。失败后记录错误和当前阶段，先查询现场；不要重复创建同一特征。只有已定位原因、且明确残留状态后才尝试修正。
3. 参数接口默认为 mm；原生 COM 长度和部分几何查询为 m，体积为 m³。按返回字段换算，不能仅看显示单位。
4. 先验收再保存，保存后关闭并只读重新打开，再次核对。新建文件只在全部要求通过后报告为成功。
5. 将“工具已加载”“查询成功”“几何正确”“草图完全定义”“尺寸关联有效”分开描述。代码测试通过不能替代真实 CAD 验收。

## 原生尺寸与方程

create_parametric_plate 默认为 use_equations=false：L/W 由原生尺寸驱动，孔位相对于邻近角点约束；T 为拉伸厚度；set_plate_parameters 同步重复的 D/E 尺寸。

这不是五个 SolidWorks 全局变量。D/E 的重复尺寸由工具统一更新；手动改其中一条不保证其他同组尺寸自动跟随。

方程模式默认关闭，须修复并验证本机 VBA/方程功能后再单独启用。原生尺寸可用并不意味着方程引擎可用。不要为了声称完全定义而固定整个草图；本配方只固定一个原点角点，其余尺寸驱动。

## 交付

给出输出零件的路径、实际验收结果、参数变更试验及未解决事项。不要宣称材料、质量、强度、公差、可制造性、装配或工程图已验证，除非本次任务实际完成相应检查。

需要界面查看时，可使用当前环境提供的 Computer Use 能力并遵循其技能；本技能不包含桌面控制插件或商业 CAD 软件安装包。

维护随附代码前，读取 [上游与本地修正](references/upstream.md)，保留第三方许可。
